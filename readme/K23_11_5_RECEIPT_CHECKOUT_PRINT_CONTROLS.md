# K23.11.5 — Checkout Receipt Print Controls

## Changes
- Customer receipt printing on checkout can be disabled through the existing receipt setting.
- Added independent Barista Copy and Kitchen Copy settings.
- Removed the customer receipt footer text “Thank you for ordering with Bigger Brew!” and “PAID/PAYMENT TAGGED”.
- Checkout confirmation modal now offers PRINT KITCHEN when kitchen items exist and the setting is enabled.
- Checkout confirmation modal now offers PRINT BARISTA when drink items exist and the setting is enabled.
- Manual copy buttons print only the selected production copy.
- Existing Bluetooth XP-58H flow is preserved.
