# K24.10 — Clear Product/Category Search After Add Order

## Change
When a product is successfully added from the employee/main ordering product grid, the `Search product or category` field is cleared and the full product catalog is restored.

## Behavior
- Successful product add -> clear search text and query.
- Variant/size/add-on customization cancelled -> preserve the current search.
- Existing cart and product selection flow is unchanged.
