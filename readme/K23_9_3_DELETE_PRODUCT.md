# K23.9.3 — Delete Product

Added a protected Delete Product action to Product Manager.

- Delete button is shown beside Edit.
- Confirmation is required before deletion.
- Deletion permanently removes the product from the catalog override.
- Product-specific sizes, variants, and option assignments are removed with the product because they are nested in the product record.
- Existing option definitions are not modified.
- Existing Add Product and Edit Product workflows are unchanged.
