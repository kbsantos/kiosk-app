# K24.9 — Today's Transactions Price Alignment

## Change
The transaction total is now displayed inside the same left-aligned details column as the item count.

### Before
The total was a separate right-aligned value immediately before the action buttons.

### After
The transaction details column shows:
- Item count
- Total price
- Payment method / status
- Modification reason, when applicable

The action buttons remain on the right.

## Scope
No transaction, receipt, printer, or pricing logic was changed. This is a layout-only change.
